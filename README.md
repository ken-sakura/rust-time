# rust-time

Rust製のレスポンシブなTUIデジタル時計アプリケーションです。  
画面中央に見やすい大きな文字で時間を表示し、tmuxやターミナルの画面分割・リサイズに合わせて自動で最適なフォントサイズ・レイアウト（秒表示や日付、枠線、フッターの有無など）に適応します。

---

## 主な特徴

- **画面中央への美しい配置**: どんな端末サイズでも垂直・水平の中央にバランスよくレイアウト。
- **インテリジェントなレスポンシブデザイン**:
  - **大画面 (Full/Large)**: 7x5の巨大ブロック文字（ExtraLarge）、秒表示（`HH:MM:SS`）、日付表示、丸角枠線、操作フッターを表示。
  - **中画面 (Medium/Split)**: 5x3ブロック文字（Large）、秒表示、日付表示、枠線。
  - **狭小ペイン (Narrow)**: 枠線を自動解除して表示領域を最大化。5x3または3x3文字、秒なし（`HH:MM`）にスマート切替。
  - **超極小ペイン (Tiny)**: 画面高さや幅が極端に小さい場合でも崩れず、1行テキスト表示（`HH:MM:SS` または `HH:MM`）にフォールバック。
- **コロン点滅 (Blinking Colon)**: 1秒周期（0.5秒ON/OFF）で時計らしさを演出。レイアウト幅がブレない等幅設計。
- **多彩なカラーテーマ**: Cyber Cyan、Matrix Green、Amber Gold、Neon Magenta、Cool Blue、Vivid Red、Pure White、Rainbow Spectrumの8色。
- **豊富なカスタマイズキー**: 秒の有無、日付の有無、コロン点滅、枠線の有無、フォントサイズの手動固定などをワンキーで即座に切り替え可能。
- **安全なターミナル復元**: 終了時や万が一のパニック時にもターミナルの生モードや画面状態を確実に復元。

## インストールと起動

### 前提条件
- Rust / Cargo (Edition 2024 対応)

### ビルド & 実行
```bash
cargo run --release
```

バイナリを直接実行したい場合:
```bash
cargo build --release
./target/release/rust-time
```

---

## キー操作一覧

| キー | 動作 |
|:---|:---|
| `q` / `Esc` / `Ctrl+C` | アプリケーションの終了 |
| `c` / `t` | カラーテーマの切り替え（全8種類） |
| `s` | 秒表示の切り替え（Auto ⇄ 常時ON ⇄ 常時OFF） |
| `d` | 日付表示の切り替え（Auto ⇄ 常時ON ⇄ 常時OFF） |
| `b` | コロン点滅の ON / OFF 切り替え |
| `w` | 外枠ウィンドウ（Border）の切り替え（Auto ⇄ 常時ON ⇄ 常時OFF） |
| `0` / `a` | 自動レスポンシブモードに復帰 |
| `1` | Extra Large (7x5 ブロック) に固定 |
| `2` | Large (5x3 ブロック) に固定 |
| `3` | Medium (3x3 ハーフブロック) に固定 |
| `4` | Small (1行テキスト) に固定 |
| `?` / `h` | ヘルプポップアップの表示 / 非表示 |

## プロジェクト構成

```
rust-time/
├── Cargo.toml          # 依存関係（ratatui, crossterm, chrono）
├── README.md           # ドキュメント
└── src/
    ├── main.rs         # エントリポイント、ターミナル管理、イベントループ
    ├── app.rs          # アプリケーション状態、レスポンシブ判定・計画ロジック
    ├── font.rs         # ASCII/Unicodeブロック文字フォント定義と文字幅計算
    ├── theme.rs        # カラーテーマ定義
    └── ui.rs           # Ratatuiによる描画レンダリング、フッター、ヘルプポップアップ
```
